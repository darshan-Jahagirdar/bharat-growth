# BharatGrowth — Deployment Guide

## Prerequisites

- [GitHub](https://github.com) account
- [Vercel](https://vercel.com) account (free tier works)
- Supabase project already set up with schema deployed

---

## Step 1: Push to GitHub

Run these 3 commands from the `BharatGrowth` project directory:

```bash
git init && git add -A && git commit -m "BharatGrowth MVP — Speed Billing for Indian SMBs"
gh repo create BharatGrowth --public --source=. --push
```

> If you don't have `gh` CLI, create the repo on github.com manually, then:
> ```bash
> git remote add origin https://github.com/YOUR_USERNAME/BharatGrowth.git
> git branch -M main
> git push -u origin main
> ```

## Step 2: Deploy on Vercel

1. Go to [vercel.com/new](https://vercel.com/new)
2. Click **"Import Git Repository"**
3. Select your **BharatGrowth** repo
4. Vercel auto-detects Next.js — leave framework preset as-is
5. **CRITICAL — Add Environment Variables** before clicking Deploy:

| Variable | Value | Notes |
|----------|-------|-------|
| `NEXT_PUBLIC_SUPABASE_URL` | `https://vyycczqhvsgkiqtxxxos.supabase.co` | Your Supabase project URL |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | `sb_publishable_zv6HeLnQhwLItuQW5bl-QA_k451iMEa` | Publishable/anon key |
| `SUPABASE_SERVICE_ROLE_KEY` | *(get from Supabase Dashboard → Settings → API)* | **Server-side only** — used for onboarding |
| `NEXT_PUBLIC_APP_URL` | *(your Vercel domain, e.g. `https://bharatgrowth.vercel.app`)* | Used for receipt QR codes |

6. Click **Deploy**
7. Wait ~60 seconds for the build to complete

## Step 3: Post-Deploy Checklist

### Supabase Configuration

- [ ] **Auth → URL Configuration**: Add your Vercel domain to "Site URL" and "Redirect URLs" in Supabase Dashboard → Authentication → URL Configuration
- [ ] **Auth → Providers → Phone**: Enable Phone provider if using real OTP (requires Twilio or MessageBird)
- [ ] **Service Role Key**: Copy from Supabase Dashboard → Settings → API → `service_role` key (the secret one, not anon)

### Vercel Domain

- [ ] After first deploy, copy your Vercel URL (e.g. `https://bharatgrowth.vercel.app`)
- [ ] Update `NEXT_PUBLIC_APP_URL` in Vercel → Settings → Environment Variables
- [ ] Redeploy for the change to take effect

### Optional: WhatsApp Business API

- [ ] Set `WHATSAPP_ACCESS_TOKEN` and `WHATSAPP_PHONE_NUMBER_ID` in Vercel env vars
- [ ] Create a `purchase_receipt` template in Meta Business Manager

## Architecture Summary

```
Browser → Vercel (Next.js) → Supabase Cloud (Mumbai)
                ↓
         /billing    → Speed billing (desktop, keyboard-driven)
         /dashboard  → Owner metrics (mobile-first)
         /login      → Phone OTP auth
         /onboarding → New shop setup
         /receipt/[id] → Thermal print receipt
         /api/whatsapp/send-receipt → WhatsApp Cloud API
         /api/onboarding → Shop + user creation
```
